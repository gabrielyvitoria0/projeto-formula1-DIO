🏎️ Formula 1 - Classificação e Pilotos
Este projeto foi desenvolvido como parte de um desafio prático na DIO (Digital Innovation One). O objetivo é criar uma página dinâmica e responsiva que exibe informações sobre a temporada de Fórmula 1, utilizando conceitos modernos de Front-end.

🚀 Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:

HTML5: Estrutura semântica do projeto.

CSS3: Estilização, incluindo layouts com Flexbox e Grid para responsividade.

JavaScript: Manipulação do DOM para interatividade (se aplicável ao seu código).

Git/GitHub: Controle de versão e hospedagem.
